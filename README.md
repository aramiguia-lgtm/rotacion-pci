# Rotación de grupos PCI Miami

App para que cada grupo arme su rotación de personal: máquinas, personal, desayuno y almuerzo, vacaciones, mes, reporte, evaluaciones y recordatorios.

- Se instala en el teléfono o la tablet desde el navegador («Instalar app» o «Agregar a pantalla de inicio»).
- Funciona sin internet una vez abierta.
- Los datos se guardan solo en el aparato. Para pasarlos a otro, usa el código de respaldo de la pestaña Grupo.

Publicada en: https://aramiguia-lgtm.github.io/rotacion-pci/
